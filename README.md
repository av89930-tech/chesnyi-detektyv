# 🕵️ Чесний Детектив (PWA)

Офлайн-застосунок для магазину: фото цінника → цифри підставляються самі → ціна за 1 кг / 1 л / 1 шт і за 100 г/мл,
підказка щодо шрінкфляції (900 г замість 1 кг тощо), порівняння з попередньою упаковкою
та список порівняння товарів (зберігається лише на пристрої).

## Розпізнавання цифр з фото
- Працює **на телефоні** (Tesseract.js, українська модель), фото нікуди не надсилається.
- Перше розпізнавання завантажує ~6 МБ (бібліотека + мова), далі — з кешу, **офлайн**.
- Знаходить: ціну (найбільше число на ціннику; голосування трьох масштабів), вагу/об'єм
  (`900 г`, `0,85 л`, `870 мл`…) і надруковану магазином «ціну за 1 кг / 1 л / 100 г».
- Якщо «ціна за 1 кг» на ціннику не збігається з реальним розрахунком — 🚨 у звіті.
- Дрібні верхні копійки («69⁹⁰») читаються не завжди: тоді в полі ціни буде «69,»
  і прохання дописати копійки — застосунок нічого не вигадує.
- Розрахунок запускається сам лише коли цифри підтверджують одна одну; інакше —
  перевірте поля (можна вибрати інший варіант кнопкою) і натисніть «Розрахувати».

## Файли
- `index.html`, `style.css` — інтерфейс
- `calc.js` — чиста логіка розрахунків (без DOM, тестується в Node)
- `app.js` — камера, форма, порівняння, встановлення
- `ocr.js` — розпізнавання на пристрої (проходи, масштаби); `ocr-parse.js` — розбір тексту (тестується в Node)
- `vendor/tesseract/` — локальні файли Tesseract.js 7 + `ukr` (Apache-2.0, див. `VERSIONS.txt`)
- `sw.js` — офлайн-кеш (network-first)
- `manifest.webmanifest`, `icons/` — встановлення на головний екран
- `test/test.js` — тести (`npm test`, залежностей немає)

## Публікація на GitHub Pages
Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)` → Save.
Через хвилину застосунок буде за адресою `https://<користувач>.github.io/chesnyi-detektyv/`.
(Альтернатива: Netlify / Vercel — просто вказати корінь репозиторію, збірка не потрібна.)

## Встановлення на телефон
- **Android (Chrome):** кнопка «Встановити» в застосунку або ⋮ → «Встановити додаток».
- **iPhone (Safari):** «Поділитися» → «На початковий екран».

> Підказка про шрінкфляцію — сигнал перевірити, а не доказ: деякі товари завжди продаються
> в нестандартній фасовці.
